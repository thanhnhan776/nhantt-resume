## Public exports/contracts

- `InteractionRoot({ experiences, projects?, achievements?, techStack?, diagrams?, initialOverlay?, children? })`
- `ExperienceTrigger({ experienceId, children })` dispatches `portfolio:experience-select` with `{ experienceId }`.
- `ExperienceSheet` renders approved public record fields and filters professional projects by matching `experienceId`.
- `OverlayState`, `overlayReducer`, `initialOverlayState` implement `none | experience | command(returnTo)`.
- `requestExperienceOpen(id)`, `requestCommandOpen()`, `requestCommandClose()` dispatch:
  - `portfolio:experience-select` `{ experienceId }`
  - `portfolio:command-open`
  - `portfolio:command-close`

The command request events are confirmed by the accepted A07 handoff. A07 defers experience selection until the palette's close-autofocus callback, so the command overlay closes before the new experience is requested. A07's scoped cancel-focus test passes.

URL behavior implemented in the root: allowlisted query IDs are read after mount; open pushes `?experience=<id>#experience`; close replaces only the `experience` query key and retains hash/other parameters; invalid query IDs are ignored and removed by replacement; `popstate` follows selection without pushing another entry.

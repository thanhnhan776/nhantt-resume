## Accessibility, responsive behavior, and themes

- Stage and connection text is not gated on JavaScript. Graph selection has an equivalent native button list (`aria-pressed`), with detail and live announcement updated through shared selection state.
- React Flow nodes/edges are focusable; node labels, controls, selected-state outline, and text labels do not rely on color alone. Fit and reset/zoom are explicit buttons.
- Graph manipulation does not capture ordinary wheel scrolling or require dragging. At narrow widths the graph is omitted in favor of the readable node list and detail; no nested graph scroll area is introduced.
- SVG and graph colors use `currentColor`/semantic theme variables. CSS disables animation and transitions under reduced motion. No continuous decorative animation is used.
- Automated coverage checks text equivalence, theme tokens, reduced-motion rules, dimensions, renderer states, unsafe/malformed data, missing SVG renderer fallback, list selection, graph selection callback, selected announcement, and details.
- No manual screen-reader, forced-colors, real-device zoom, or contrast-ratio audit was performed; A09 should include these in its accessibility review.

## Frozen B1 interaction contracts

These signatures are integration contracts for A04–A07/A08, not implementations
in A03. Import domain types from `@/types`.

```ts
type OverlayState =
  | { type: "none" }
  | { type: "experience"; experienceId: ContentId }
  | {
      type: "command"
      returnTo: "none" | { type: "experience"; experienceId: ContentId }
    }

interface ExperienceTriggerProps {
  experienceId: ContentId
  children: React.ReactNode
}

interface ExperienceSheetProps {
  experienceId: ContentId
  selectedProjectId?: ContentId
  onClose(): void
}

interface InteractionRootProps {
  experiences: readonly Experience[]
  initialOverlay?: OverlayState
}

interface QuickActionBarProps {
  actions: readonly ActionDescriptor[]
  onAction(action: ActionDescriptor): void
}

interface DiagramContainerProps {
  diagram: TechnicalDiagram
  selectedModuleId?: ContentId
}

interface CodeViewProps {
  snippetId: ContentId
  content: string
  accessibleLabel: string
  title?: string
  presentation?: "plain-text" | "formatted"
}
```

- **Experience selection event:** the owner-approved browser event is
  `portfolio:experience-select`, detail shape
  `CustomEvent<{ experienceId: ContentId }>`. Send only the allowlisted stable
  ID—not the full experience record. The trigger and InteractionRoot use this
  same contract.
- **Action descriptors:** data-only `ActionDescriptor` from `@/types`; IDs are
  stable, targets are approved, and kinds are the existing `section | email |
  linkedin | github | resume` union. A04 renders approved quick actions; A07
  consumes the same allowlist for the palette. Do not invent targets or pass
  component callbacks in serialized Server Component props.
- **Diagram/code:** DiagramContainer receives an approved `TechnicalDiagram`
  and optional selected module ID. CodeView receives an approved static snippet
  and accessible label; never execute snippets or include secrets/private
  employer material. SVG/text equivalents remain mandatory for diagram access.
- **Overlay owner:** A05's InteractionRoot is the sole modal/focus owner. State
  transitions are `none → experience`, `none → command`, and
  `experience → command(returnTo=experience)`; closing command restores its
  recorded prior state after command close completes. Do not nest focus traps.
- **URL/history:** valid selection is `/?experience=<stable-id>#experience`;
  validate after hydration against the public registry. Opening uses
  `history.pushState`; close uses `replaceState`, removing only `experience`
  while preserving unrelated query/hash. Invalid IDs are ignored. `popstate`
  synchronizes selection without adding another history entry. Focus and scroll
  restoration belong to A05; A07 requests actions through the shared contracts.

These details confirm the accepted contracts in
[decision 03](../decisions/03-export-contracts.md) and
[architecture](../architecture.md); they do not authorize feature code in A03.

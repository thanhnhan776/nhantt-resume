## Public contracts and behavior

- `ACTIONS` is the shared allowlist used by the command palette and
  `QuickActionBar`; `executeAction` rejects descriptors outside that allowlist.
- Section actions target the existing IDs: `summary`, `experience`,
  `projects`, `education`, and `contact`.
- Experience selection uses the approved `portfolio:experience-select` event.
  `CommandPalette` consumes A05's `portfolio:command-open` and
  `portfolio:command-close` request events. Experience selection from the
  palette is deferred until Radix's close-autofocus callback, so the command
  overlay closes before a new experience is requested. Cancellation returns to
  the existing sheet; the focused descendant is checked by the scoped test.
- The shortcut is Cmd/Ctrl+K, toggles the palette, and ignores editable,
  composing, prevented, and extra-modifier key events.
- Clipboard denial is announced and displays the approved email address in a
  selectable field. PDF navigation is exposed only when the approved profile
  resume descriptor exists. The current descriptor is
  `/resume/Tran-Thanh-Nhan_Resume_VN_Remote.pdf`, labeled “View résumé PDF”.
- `CodeView` defaults to the narrative and offers a semantic `pre`/`code`
  alternate with a horizontally contained, keyboard-scrollable region and
  theme tokens. No approved production code snippets were found in the project
  data. CodeView fixtures are test-only reconstructions; A07 does not publish
  them as portfolio content. Keep the narrative available when no approved
  snippet exists.
